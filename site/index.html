Persian Phonetic IME

Type Latin letters, get Persian script. A free, open-source input method for Windows.

Download Source on GitHub
Pre-release. The installer is unsigned, so Windows SmartScreen will warn you, and the input method may be ignored in some modern Windows apps. It has had little testing on real machines. Keep another keyboard layout available (Win+Space) in case you want to switch back.

How it works

The mapping is letter by letter, with no dictionary guessing. You spell the letters that appear in the Persian word. Vowels are typed only when they appear in the Persian spelling, and every a becomes ا.

You typeYou get
slamسلام
khubخوب
shirشیر

Features

  • The whole current word is shown underlined while you type. Space, Enter or punctuation commits it. Backspace edits the Latin letters, Escape cancels.
  • Ambiguous letters have a numbered candidate list. For example s can be س ص ث. Press Tab or Down, then 1–9.
  • Persian digits and punctuation by default, and Shift+Space for the zero-width non-joiner (می‌خواهم).
  • Optional word suggestions from a bundled dictionary, with a profanity filter.
  • Configurable with an optional TOML file. A mistake in it never stops you typing.

Install

  1. Download PersianPhoneticIme-0.1.0-x64.msi from the Releases page. Check it against the attached .sha256 file.
  2. Run it. It needs 64-bit Windows 10 or later and asks for administrator approval.
  3. Switch to it with Win+Space, or add it under Settings, Time & language, Language.

Privacy

No network access, no telemetry, and typed text is never logged or stored. Read the privacy policy.
